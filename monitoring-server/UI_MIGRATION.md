# 모니터링 화면 이식 및 새 서버 연결

## 범위

화면 출처: `kalmans251/ECO_LUMINOUS_SPRING_BOOT_SERVER`, commit
`11959919ffcd7db9607960c25b8774401c359ec0`의 `static/index.html`.
기존 카드 배치, 색상, 로고, 지도, 난간 선택, LED/음악, SOS/PTT, 설치 정보,
예약, 연락망, 레이더/CCTV 전환을 유지했습니다. 기존 서버 Java 코드,
고정 API key, STOMP 전역 토픽, 5바이트 상태 패킷은 사용하지 않습니다.

새 구조는 `사용자 → 현장 권한 → 난간 Pi → 난간 → 선택적 카메라`입니다.
난간의 서버 UUID와 Pi 내부의 1..255 난간 번호를 구분합니다.
다른 Pi의 `1번 난간`은 서로 다른 장치입니다.

## 현재 동작하는 범위

| 화면 기능 | 새 서버 처리 | 현장 연결 조건 |
|---|---|---|
| 로그인 | BCrypt, 세션 쿠키, CSRF | 최초 관리자 비밀번호 설정 |
| 사용자/현장 관리 | 관리자만 등록, 현장별 조회자/운영자 | 우측 상단 관리 |
| 난간 선택/일괄 제어 | 최대 50개 선택, 변경 옵션만 요청 | 새 장치 WebSocket 어댑터 필요 |
| 전원/LED/음악/프로젝터/볼륨/슬립 | 검증된 명령, Pi별 순차 전달, 요청 이력 | `DEVICE_PROTOCOL.md` |
| 적용 상태 | QUEUED/SENT/RECEIVED/PLC_SENT/APPLIED/UNKNOWN 구분 | 펌웨어의 실제 확인을 Pi가 전달 |
| 통화/PTT | 한 Pi 버스에 한 통화, 운영자 소유권, 종료 확인 | Pi 어댑터 및 Codec2 서비스 |
| 실시간 계측/레이더 | 장치 소유권·범위·시각 검증 | 새 telemetry 입력 |
| 예약 | 한국 시간 시작/종료 전원 명령 | 실행 시 온라인·운영 권한 필요 |
| 설치 위치 | 현장 권한 검사 후 DB 저장 | 지도 드래그 후 저장 |
| 통계 | 실제 계측을 시간 적분, 누락 구간 제외 | telemetry 필요, 현재 90일 보존 |
| 비상 연락망 | 저장 연락처·CSRF·권한·중복/속도 제한 | SMS 공급자 설정 |
| CCTV | 등록 카메라 iframe, 현장 접근 승인 API | MediaMTX/Nginx 별도 구성 |

예약은 저장 즉시 전원을 바꾸지 않습니다. 해당 시각에만 요청하며,
서버가 꺼져 있거나 Pi가 오프라인이면 지난 명령을 재생하지 않습니다.
예약 해제는 처리 내역의 예약 목록에서 할 수 있습니다.
연간 통계도 보존된 90일 데이터까지만 표시하며 이를 화면에 명시합니다.

기본 LED 6개와 음악 LED 3개의 선택을 P4 패턴 명령에 연결했습니다.
세부 동작과 로컬 시험 명령은 [LED 디자인](../hello-p4/LED_DESIGN.md)을 참고하세요.

## 현재 펌웨어에서 제공하지 않는 기존 화면 옵션

자동 전원 선택, 이전 곡, 곡 번호 지정, 비상벨 자체 ON/OFF, 센서 자체 ON/OFF는
위치를 유지하되 미지원으로 비활성화했습니다. 현재 프로토콜에 없는 명령을
다른 명령으로 바꾸거나 성공으로 표시하지 않습니다.
음악 재생 모드는 현재 펌웨어의 sequential/shuffle/age로 연결합니다.
설정 초기화는 기본 제어 옵션을 준비하며 사용자가 전체 적용을 눌러 요청합니다.

## 계정과 운영 제약

- 조회자 VIEWER는 담당 현장 조회만, OPERATOR는 담당 현장의 제어/예약/연락망을 관리합니다.
- 전체 관리자는 현장/장치/계정을 등록하고 권한을 부여합니다. 회원가입으로 임의 현장 권한을 얻지 않습니다.
- 장치 토큰은 DB에 BCrypt 해시로 보관하며 브라우저에 전달하지 않습니다. 토큰은 UTF-8 32~72바이트로 생성합니다.
- 같은 명령 요청 UUID를 재사용하면 기존 결과를 반환합니다. 내용이 달라지면 409입니다.
- 명령 시간 제한은 15초입니다. 응답 손실/재시작은 UNKNOWN이며 자동 재전송하지 않습니다.
- 통화 종료 확인을 잃으면 점유를 보존합니다. 소유자 또는 관리자가 종료를 다시 요청합니다.
- 현재 H2 파일 DB와 단일 Spring 인스턴스 구성이며, 다중 사용자/현장은 지원하지만 서버 다중 복제는 지원하지 않습니다.
- 운영 공개 전 계정 비밀번호 재설정·장치 토큰 교체와 로그인 시도 제한은 별도로 추가해야 합니다.
- HTTPS 운영 시 `COOKIE_SECURE=true` 및 신뢰된 Nginx를 사용하세요. 브라우저 마이크는 HTTPS 또는 localhost에서 사용합니다.
- 브라우저 새로고침/연결 종료가 물리 통화 종료를 뜻하지 않습니다. 재접속 후 종료 상태를 확인해야 합니다.
- 실물 Pi/PLC/P4/WROOM/S3에 대한 종단 테스트는 별도로 필요합니다. 이 변경은 그 펌웨어를 수정하지 않습니다.

## 문자

환경변수 `SMS_API_KEY`, `SMS_API_SECRET`, `SMS_FROM`을 설정하면 SOLAPI로 요청합니다.
공식 HMAC 규격: https://solapi.com/developers/api/authentication-api-key
연락처 저장 후 명시적인 발송 확인을 거칩니다. ACCEPTED는 공급자 접수이며
수신자 도착 확인이 아닙니다. 실패/타임아웃을 자동 재발송하지 않습니다.
자동 테스트는 실제 문자를 보내지 않습니다.

## 음성 변환 서비스 (서버 PC)

Linux/WSL에서 `sudo apt install libcodec2-dev` 후, Spring과 같은 머신에서:

```bash
export CODEC_TOKEN='<32자 이상의 별도 임의 토큰>'
python tools/codec_adapter.py
```

Spring 터미널에도 같은 `CODEC_TOKEN`을 설정하고 재시작합니다.
Windows 네이티브는 Codec2 DLL 경로를 `CODEC2_LIBRARY`로 지정할 수 있지만,
현재 검증은 Linux libcodec2에서 수행했습니다. Docker Spring과 호스트의
127.0.0.1은 다르므로 기본 compose는 음성 서비스를 포함하지 않습니다.
음성 통합 테스트는 우선 같은 Linux/WSL 호스트의 JVM과 Python으로 진행하세요.

브라우저는 8 kHz mono signed int16 little-endian 160ms PCM을 보냅니다.
서버가 Codec2 2400의 8프레임(48바이트)으로 변환하여 Pi에 전달합니다.
난간 음성도 반대 방향으로 변환합니다. 변환 서비스는 loopback 전용이며 별도 토큰이 필요합니다.
각 통화/방향의 Codec2 상태를 분리하고 60초 유휴 상태를 정리합니다.
실제 통화 권한과 방향이 확인되어야 브라우저 음성이 전달됩니다.
