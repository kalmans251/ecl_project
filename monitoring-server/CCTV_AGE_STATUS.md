# CCTV 연령대 웹 확인

1. 이 변경을 병합하고 monitoring-server를 업데이트합니다.
2. 기존 환경 변수와 DB를 유지한 채 Spring Boot를 재시작합니다.
3. 로그인 후 /cctv-test.html을 열고 Ctrl+F5로 새로고침합니다.
4. 카메라 ID를 입력하면 2초마다 상태가 갱신됩니다. 영상 재연결은 하지 않습니다.

화면은 모델 준비 상태, 최근 감지 시각과 이벤트 번호, 추정 연령대, 사람 진입 및 연령대 전달 결과를 표시합니다.
현재 분석 프로토콜은 정확한 나이가 아닌 10/20/30/40대 그룹을 전달합니다.
새 진입 이벤트에 연령 결과가 아직 없으면 이전 사람의 결과 대신 결과 미수신을 표시합니다.
keep은 기존 선택 유지이며 연령 분석 성공을 뜻하지 않습니다.
분석 상태가 오래되거나 비활성인 경우 이를 별도로 표시합니다. 최근 기록은 현재 화면의 모든 사람에 대한 결과가 아닙니다.

PLC_SENT는 게이트웨이의 전달 처리 응답입니다. 실제 음악 재생 여부는 별도로 확인하세요.
권한이 있는 카메라의 기록만 기존 인증된 상태 API로 조회합니다.
Pi/P4/WROOM/S3 펌웨어와 DB 초기화는 필요하지 않습니다.

검증:
- node --test tools/cctv-age.test.cjs (monitoring-server 디렉터리)
- mvn test -Dtest=CctvTest
