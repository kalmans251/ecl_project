# 비상벨·센서 수신 ON/OFF
웹 기능 설정에서 선택한 뒤 **전체 적용**을 누릅니다. 서버 → Pi → P4의 토큰이 일치하는 적용 응답을 확인하고, 상태조회 v5의 실제 값으로 표시합니다.

- **비상벨 OFF**: P4가 S3의 새 비상 호출 시작을 받지 않습니다. S3에는 종료 확인을 돌려주어 재전송이 누적되지 않게 합니다. 진행 중 비상/통화에서는 일반 제어가 거절되므로 기존 호출을 강제로 끊지 않습니다.
- **센서 수신 OFF**: P4가 레이더/CCTV 감지 이벤트를 처리하지 않고, 레이더 좌표 조회는 사용 불가 상태를 반환합니다. 감지에 의한 카운트·연령 음악 선택·슬립 복귀도 멈춥니다. 센서 하드웨어 전원을 끄거나 CCTV 영상/서버 분석을 중단하는 기능은 아닙니다.
- 두 설정은 P4 RAM에 유지되며 **재부팅하면 ON**입니다. ON 복귀 시 센서 수신은 새 레이더 샘플부터 표시합니다.
- 웹의 **비상 알림음** 스위치는 PC 소리에만 적용되며 현장 **비상벨**과 별개입니다.
- Pi 명령: `alarm 1 on|off`, `sensor 1 on|off`.

## 배포
모니터링 서버·난간 Pi·P4를 함께 업데이트합니다. WROOM·S3 변경은 없습니다. 구형 P4는 신규 제어를 거부하며 v1..4 상태는 신규 두 설정을 미확인으로 표시합니다.

## 프로토콜
기존 APPLY/토큰을 사용합니다. 비상벨은 EMERGENCY(0x06) START/STOP, 센서 수신은 DETECTION(0x09) START/STOP입니다. P4 확인 데이터는 1바이트 ON=01/OFF=00이며 Pi와 서버가 요청값 일치를 검사합니다.
상태 v5는 v4의 34바이트 뒤에 alarm_enabled, sensor_enabled 0/1 두 바이트를 추가합니다. v1..4 요청도 계속 지원합니다.
