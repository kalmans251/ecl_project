# 음악연동 열기와 기본 재생모드

- P4와 WROOM의 부팅 기본 재생모드는 나이기반재생(AGE)입니다.
- 연령 판별 전/해당 연령 폴더가 비었을 때에는 기존 default 폴더를 사용합니다.
- 레이더로 전환하면 연령 정보가 없으므로 기존 정책대로 순차재생으로 전환합니다.
- UI 명칭은 순차재생 / 랜덤재생 / 나이기반재생입니다.

음악연동 탭을 클릭하면 선택한 난간 하나의 현재 폴더 첫 페이지(최대 8곡)를 조회하고,
WROOM MUSIC_INFO 응답에서 현재 파일명, 실제 음량, 실제 재생모드를 읽습니다.
탭에서 보이는 폴더는 사용자가 선택한 폴더이며 자동으로 다른 연령 폴더로 이동시키지 않습니다.
트랙 선택란의 안내에 현재 파일명을 표시합니다. 다른 폴더에 같은 파일명이 있을 수 있으므로
파일명만 보고 특정 목록 항목을 재생 대상으로 자동 선택하지 않습니다.

이미 수정 중인 음량/재생모드는 조회로 덮어쓰지 않습니다.
조회 중 다른 난간/현장/폴더를 선택한 경우 늦게 온 결과를 해당 화면에 적용하지 않습니다.
조회 중에는 전체 적용 대신 조회 완료 후 적용하도록 안내합니다.
단순히 탭을 여는 동작은 음량/재생모드를 변경하지 않습니다. 변경은 기존 적용 절차를 사용합니다.
목록 조회에는 PLC 왕복 시간이 걸리며 '장치 응답 확인 중'을 표시합니다.

MUSIC_INFO 기존 응답 prefix(상태 1 + 위치 4 + 파일명 길이 1 + 파일명)는 유지하고
뒤에 음량 1바이트(0..100), 재생모드 1바이트(1=순차, 2=랜덤, 3=나이 기반)를 추가합니다.
Pi는 기존 길이도 허용하며 구형 WROOM에서는 실제 음량/모드를 만들어내지 않습니다.
music.list 서버 결과에 선택적 settings 객체를 추가하며 이전 6필드 목록 결과도 허용합니다.

서버, Pi, P4 및 WROOM을 업데이트하고 서버/Pi를 재시작한 뒤 웹을 Ctrl+F5로 새로고침합니다.
S3 업데이트는 필요 없습니다. 실제 장비의 조회 시간과 음량/모드 반영은 현장 확인이 필요합니다.
