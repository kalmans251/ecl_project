# LED 9개 패턴 · 순차 재생 · 현재 날씨 연동

## 업데이트
서버, 난간 Pi Python, P4 펌웨어를 함께 업데이트한다. WROOM/S3 변경은 없다.
DB는 유지한다. schema.sql이 weather_auto 테이블을 추가한다.
브라우저는 Ctrl+F5로 새 파일을 읽는다. P4의 status v4와 Pi 디코더가 패턴·순차 간격을 보고한다.

## 기본 LED
기본 1~6 패턴은 그대로다. 7=기존 맑음, 8=기존 비/흐림, 9=기존 눈 효과다.
패턴을 직접 선택한 후 전체 적용한다.
순차 재생을 선택하면 P4가 1→2→…→9→1로 반복한다.
전환 간격은 1~120초, 기본 10초다. 웹을 닫거나 서버 연결이 끊겨도 P4가 전환한다.
9개 패턴은 수동 선택이고, 10번째 항목은 별도 효과가 아닌 순차 재생 옵션이다.
통화·비상·슬립 등 기존 출력 우선순위는 유지된다.

## 날씨 연동
- 현재 날씨 자동 연동: 선택한 난간의 저장 좌표로 서버가 Open-Meteo 현재 weather_code를 조회한다.
  최초 적용 시 즉시 조회·명령 접수 후 실제 장치 확인 절차를 따른다.
  설정은 DB에 유지되며 웹이 닫혀 있어도 서버가 약 10분 주기로 재적용한다.
  API 실패/오프라인/통화/다른 명령 처리 중에는 이전 실제 출력 상태를 바꾸지 않고 다음 확인 시 재시도한다.
  서버가 꺼져 있으면 마지막으로 적용된 패턴을 유지한다.
- 직접 선택: 맑음 / 비·흐림 / 눈 중 하나를 선택한다.
- 기본/음악 모드나 수동 날씨 패턴을 웹에서 적용하면 해당 난간의 자동 날씨 설정을 해제한다.
- 자동 연동 활성화는 난간 1개씩 수행한다. 저장 좌표와 해당 현장의 운영 권한이 필요하다.
- 날씨 데이터는 현장 실측이 아닌 좌표 기반 외부 기상정보다.
- API: https://open-meteo.com/en/docs (운영 시 제공자의 서비스 이용 조건과 허용량을 확인한다.)

## Pi 직접 테스트
동시에 main.py와 다른 PLC 리더를 실행하지 않는다.
- led 1 basic 7 / led 1 basic 8 / led 1 basic 9
- led 1 sequence 10
- led 1 weather clear / led 1 weather rain / led 1 weather snow

## 장비 검증
1. 7~9 선택 후 실제 스트립에서 기존 날씨 효과와 같은지 확인.
2. 순차 2초로 설정하여 18초마다 한 바퀴가 반복되는지 확인.
3. 웹을 닫아도 순차 재생이 이어지는지 확인.
4. 자동 날씨 활성화 후 서버·Pi 명령 결과와 실제 날씨 패턴을 확인.
5. 수동 패턴 적용 후 weather_auto가 false로 바뀌고 자동 명령이 중단되는지 확인.
6. 통화·비상·슬립 시 기존 우선순위와 복귀 동작을 확인.
