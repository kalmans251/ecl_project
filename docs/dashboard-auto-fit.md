# 관제 화면 자동 맞춤

PC 관제 화면은 2400×1350 논리 화면을 기준으로 전체를 비례 확대·축소합니다. 기존 1920×1080, 브라우저 80% 화면을 기준으로 한 배치입니다. 평소에는 브라우저 배율 100%로 사용하면 됩니다.

- 실제 브라우저의 가용 너비와 높이 중 작은 배율을 선택합니다. 모니터 해상도와 브라우저 도구 모음 높이는 다를 수 있습니다.
- 화면 비율이 다르면 남는 공간에 여백이 생깁니다. 카드 비율은 유지합니다.
- 최소 배율은 0.5입니다. 1200×675보다 작은 창에서는 스크롤하며 사용합니다. 모바일 전용 세로 UI는 아닙니다.
- 창 크기 변경과 일반 브라우저 확대·축소 시 다시 계산합니다. 터치 핀치 줌은 브라우저 기본 확대 동작을 유지합니다.
- 기존 카드의 너비 기반 미디어 쿼리는 dashboard 컨테이너 쿼리로 변경했습니다. 축소된 창에서도 카드가 다른 열 배치로 재편되지 않습니다.
- 비상 호출 팝업, 자체진단, 설정 적용 창, 관리 다이얼로그와 알림은 배율 캔버스 밖에서 실제 화면 기준으로 표시합니다.

변경 파일은 서버 정적 리소스입니다. 서버 업데이트 후 Ctrl+F5로 갱신하세요. Pi와 ESP32 펌웨어는 변경하지 않습니다.

검사: `node monitoring-server/src/test/js/dashboard-fit.test.cjs`

실제 환경에서는 창 크기를 변경하면서 지도 마커 선택·드래그, CCTV, 자체진단과 설정 적용 창 표시를 확인하세요.
